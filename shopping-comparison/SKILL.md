# Compare seller offers

Start from the supplied shortlist or product links. Use shopping search for discovery when the user needs candidates. A search result is a lead. A recommendation needs evidence from the seller's listing.

Read the actual link destinations. The same product name can appear at several sellers. Keep each listing's exact URL alongside its seller, observed details and availability as you work. On a marketplace, several sellers can share one hostname. Use the seller shown on the listing when available.

Check coverage across the requested sellers early. If a listing has ended, continue with other listings. If several distinct links at one seller return the same error, move on to another seller and describe the access limitation. An error page cannot establish that an item sold out. Inspect the remaining accessible candidates that could change the result.

Use the current browser tab when it works for the task. When the user wants to watch, show the listing being checked in the foreground. Batch related reads when practical and inspect the results before opening more links from a failing seller.

Build the answer from the verified records. Compute the requested measure for each qualifying offer, sort the records by that value, and render the rows with the URLs you collected. Check the order, link destinations, and any qualification that affects the decision, such as shipping or condition. If a seller went unchecked, say so and limit the conclusion to the sources you reached.
