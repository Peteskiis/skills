# Work with a support representative

Identify the conversation, the outcome the user requested, and any limits on what you may agree to. Read recent messages before sending a reply. After reconnecting, check whether the last message arrived before sending it again.

Allow a representative time to respond. Use the wait they gave you. Otherwise, a 30–60 second browser time wait and a targeted read of the conversation usually fits a live chat. A timeout waiting for particular words can occur while the chat is healthy. Check the latest message, queue status or disconnect notice before acting. Keep the session open while a representative is working.

Speak in the customer's first person when carrying out their instructions. For example, “I left the carts at the curb on Monday. Please confirm when you'll collect them.” Answer routine questions directly using facts the user supplied or verified account details. If asked for the name on the account, give the verified name. Use the customer’s own information for questions about their identity or relationship to another person. If verification requires a missing fact, keep the chat open, ask the user privately for that fact, and relay their answer. When the user answers in the chat, read the exchange and continue from the representative's reply.

Use the Computer's private handoff for required protected input. Ask the user when a proposed fee, substitution or commitment exceeds their instructions.

At the end, distinguish what the representative confirmed from what they estimated or promised to investigate. Provide any case reference and next action from the conversation.
